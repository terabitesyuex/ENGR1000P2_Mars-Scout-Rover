# Calibration

Calibration is not performed in Phase 0. This file records the future calibration responsibilities.

## Future Calibration Items

- Confirm LiDAR forward direction relative to rover chassis.
- Confirm native zero-angle direction.
- Record fixed mounting height.
- Record fixed mounting position relative to rover frame.
- Confirm range bias against known distances.
- Confirm angular orientation using known wall geometry.
- Record reflectivity or quality thresholds after official scan format is verified.

Calibration changes must be recorded in `CHANGELOG.md`.
